# Playwright TypeScript Automation Framework

A clean starter automation framework built with **Playwright + TypeScript** for UI test automation.

## Tech Stack

- Playwright Test
- TypeScript
- Node.js
- Chromium & Firefox
- HTML reporting

## Project Structure

```text
.
├── tests/
│   └── login.spec.ts
├── playwright.config.ts
├── package.json
└── README.md
```

## Setup

```bash
npm install
npx playwright install
```

## Run Tests

```bash
npm test
npm run test:headed
npm run test:debug
npm run report
```

## What This Demonstrates

- Playwright browser automation
- TypeScript test development
- Cross-browser execution
- Assertions and test organization
- Screenshots, video, and trace configuration
- HTML test reporting
