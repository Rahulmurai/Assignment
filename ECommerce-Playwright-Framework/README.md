# E-Commerce Playwright Automation Framework

## Tech Stack
- Playwright
- TypeScript
- Page Object Model (POM)
- API Testing
- Data-Driven Testing
- GitHub Actions

## Features
- Login and Logout Automation
- Product Search Validation
- Add to Cart and Remove from Cart
- Checkout Workflow Testing
- Cross-Browser Testing (Chromium, Firefox, WebKit)
- HTML & Allure Reporting
- Screenshots, Videos and Trace Viewer
- API Validation using Playwright Request Context

## Framework Structure
pages/
tests/
fixtures/
utils/
test-data/
.github/workflows/

This project demonstrates a scalable Playwright + TypeScript automation framework following industry best practices.
